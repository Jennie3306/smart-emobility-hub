# Sơ đồ kiến trúc

- File nguồn `.drawio` để trong thư mục này, ảnh xuất để trong `../figures/`.
- Đặt tên theo quy ước: `m3_state_vehicle.png`, `architecture_component.png`.
- Chỉ TV3 sửa sơ đồ kiến trúc tổng; mỗi module tự quản sơ đồ của mình.
- Sơ đồ phải phản ánh code tại thời điểm chốt và dùng đúng tên class, trạng
  thái và sự kiện trong module tương ứng. Các sơ đồ M6 dùng tiền tố `m6_` và
  ảnh được report tham chiếu có hậu tố `.drawio.png`.
